# 破局 · 企业运营训练场

在八个季度里经营一家公司，与 24 个策略对手竞争；从每项决策、现金变化和公司对比中学习。此仓库独立保存“破局”，与 C/C++ 学习平台分开。

## 第一次使用，从这里开始

1. 在本仓库的 **Releases** 页面，下载 `Poju-Deploy-v2.1.1.zip`。
2. 将压缩包**完整解压**到一个固定文件夹，不要在压缩包里双击运行。
3. 安装 [Node.js 24](https://nodejs.org/en/download)。安装后重新打开终端；输入 `node --version` 应显示 `v24` 开头的版本。
4. Windows 用户双击 `启动-本机预览.cmd`，并保留弹出的窗口。
5. 在 QQ 浏览器、Edge 或 Chrome 打开 **http://localhost:8080**。请不要在地址栏输入文件夹路径，也不要双击 `public/index.html`。
6. 首次启动后，在解压目录的 `data/owner-code.txt` 中找到自动生成的负责人码，只由负责人保管。
7. 网页选择“负责人登录”，输入该码。登录后可生成 12 位快捷码，再为每位成员创建独立成员码。

发布包包含编译好的网页，不需要 `npm install`。它需要 Node.js 24；这是本地服务程序，不是直接打开的单文件网页。手机访问、团队共享及服务器部署见下面的详细指南。

## 已有功能

- 25 家公司、八季度经营；快速练习和每季 30 分钟两种模式。
- 1–10 级对手难度，采购、生产、定价、研发、营销、资金和低碳策略共同作用。
- 工厂式全场动作回放，可暂停、逐步观看；选择任意对手，与自己的公司比较。
- 每季全部公司的利润榜，区分当季排名和累计排名；筛选前五时保留自己的公司。
- 11 项决策逐项解析：含义、生效时间、现金与利润、计算、结果、下次检查和单项回测。
- 详细复盘、利润差分解和固定同季市场的策略实验室。
- 丰田、比亚迪、Inditex 企业案例，保留公开来源与教学假设的区别。
- 姓名与独立成员码登录；负责人团队看板、进度、草稿、练习时长和 CSV 导出。
- SQLite 持久化、数据库迁移、备份脚本；电脑和手机响应式界面。

## 源码运行

使用 Node.js 24，在仓库根目录依次运行：

```sh
npm ci
npm test
npm run build
npm start
```

浏览器打开 `http://localhost:8080`。发布打包运行 `npm run package`，文件生成在 `build/`。

## 训练定位

这是独立教学模型，不复制官方比赛的未公开算法。对手是模型内的策略程序，不是真实参赛队伍；难度不代表真人水平认证。案例中的公司经营事实与模拟参数需要分别阅读。练习可以帮助理解决策，但不能保证比赛名次。

此仓库与发布包均不包含现有平台的数据库、成员记录、负责人码或服务器私密配置。首次启动创建自己的空白数据。
