# 从第一局到详细复盘

## 第一步：选择练习目标

进入“训练大厅”，选择基础对抗、价格战、原料涨价或碳价上行。初学者先选基础对抗，难度从 1–3 开始；掌握后逐步提高到 5–7，再挑战 8–10。这里的等级只改变模拟对手的判断方式，不能换算为真实校赛名次。

快速训练由自己决定何时结算；限时实战在筹备后每季 30 分钟，到期会在后续读取或提交时按保存方案结算。不要把最后一秒未保存的输入当作已提交方案。

## 第二步：筹备公司

1. 点击“创建实战”，先进入 Q0 筹备。
2. 设置生产线、员工、开局原料和研发。
3. 看右侧“决策预检”，确认支出不超过 650 万，现金留有余量。
4. 产能取设备和人员产能的较小值，不是两者相加。
5. 点击“完成筹备，进入 Q1”。筹备费用会影响累计利润；设备、原料的资产处理与费用不同。

## 第三步：逐个检查 11 项经营决策

每季先看期初现金、原料、成品、产能、应收账款和债务，再填方案。“决策行为识别”下的每个条目都能展开；它会解释当前数字如何影响结果。

| 决策 | 操作前先检查 | 本模型的主要时间点 |
| --- | --- | --- |
| 产品售价 | 单位贡献、预计需求、对手上季行为 | 当季影响分配的需求和销售收入 |
| 计划产量 | 期初成品、原料、人员和设备瓶颈 | 实际产量受资源限制，不一定等于计划 |
| 普通订货 | 下季生产需要多少原料 | 本季付款、下季可用于生产 |
| 紧急采购 | 当季原料缺口是否值得补 | 本季可用，原料价为普通价的 1.5 倍 |
| 新增员工 | 下季设备是否有余量、工资能否覆盖 | 本季付相关成本和工资，下季贡献产能 |
| 新增生产线 | 下季需求、人员配套和现金 | 每条 180 万，下季投入生产 |
| 营销投入 | 新增销量能否覆盖投入、存货够不够 | 当季计费用，模型还记录品牌与营销作用 |
| 研发投入 | 品质变化能否换来销量或价格收益 | 当季提升品质并计入费用 |
| 绿色投入 | 后续排放与剩余经营季度 | 下季降低碳强度；末季投入没有下季经营回收 |
| 购买碳配额 | 预计排放、免费与存量配额 | 当季使用，不足时按模型补足并产生额外成本 |
| 融资安排 | 销售前付款、信用额度和利息 | 正数借款、负数还款，利润与现金分别计算 |

模型里的多数金额用“万元”，售价用“元/件”，数量用“件”；不要把售价的元直接与万元费用相加。

在“我这样决策的理由”写下预期：例如预计少生产可以降低成品积压，预计提价能提高贡献。理由不会被自动判定正确，结算后应对照实际结果。

## 第四步：提交并看全场动作

1. 确认页面显示方案已保存、没有范围错误。
2. 点击“确认决策并结算”。正式结算记录保留。
3. 在“公司赛场”点“播放全场”或“下一步”。
4. 按采购物流、生产制造、市场销售、融资投资和利润结算逐段看 25 家公司。
5. 可筛选“当季利润前五 + 我的公司”；即使自己不在前五，也保留自身对比位置。
6. 点任一公司的卡片查看完整操作和策略识别。

动画展示的是**已结算季度的阶段回放**。没有向你泄露对手尚未提交的真实想法，也不是现实公司正在发生的行为。

## 第五步：读懂当季排名

“当季全场排名”列出全部 25 家公司。用上方 Q1–Q8 切换季度，读取当季利润、销量、比上季变化、累计利润和累计名次。并列使用 1、1、3；当季未经营显示“—”。当季第一不一定是累计第一。

选择其他公司后，“与我的公司”对比保留自己的结果。先找利润差，再看售价、销量、成本、费用和现金；避免只凭对手所属策略名称判断好坏。

## 第六步：逐项复盘

进入“详细复盘”，选择季度和公司。建议依次阅读：

1. 本季发生了什么：由期初资源和实际选择解释结果。
2. 利润差分解：理解与领先者的差距来自哪里。分解按固定顺序计算，不能全部当作单项策略的因果效果。
3. 11 项决策：逐项展开含义、时间、现金、利润、计算与下次检查。
4. 单项回测：只替换一项，比较利润、现金等变化。回测固定该季市场和其他公司选择。
5. 策略轨迹：检查自己是否根据情景调整，而不是每季机械复制。

## 第七步：在实验室验证改进

选已结算季度，修改一组方案后运行对比。不覆盖正式结果。先记“我预计会怎样”，再看利润、库存和现金是否符合预期。固定同季条件的回测不包含未来对手的重新响应；下季投资回收还需要新开一局检验。

## 第八步：案例训练

进入“企业案例操盘”，先读公司公开资料与来源，再读“迁移到训练中的问题”和模型限制，完成理解题，创建相应案例实战。案例指标是教学目标，不是对真实企业运营系统的完整复制。

## 建议的练习记录

每局结束记录：情景与难度、最重要的一季、原先预期、实际差异、证据、下一局只调整什么。能解释“为什么”比只多刷一局更有助于学习。
